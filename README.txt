ماسح سيريالات Newland N950 - نسخة الجوال

الوظائف:
- مسح باركود SN بالكاميرا.
- يقبل فقط NCD + 9 أرقام.
- يمنع التكرار.
- عداد الأجهزة.
- حفظ القائمة داخل الجوال تلقائيًا.
- حذف جهاز أو آخر جهاز أو مسح الكل.
- نسخ الجدول.
- تحميل ملف Excel بصيغة .xls.
- يعمل كتطبيق PWA من GitHub Pages.

طريقة النشر:
1) أنشئ Repository جديدًا على GitHub مثل: n950-scanner
2) ارفع:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
3) Settings > Pages
4) Source: Deploy from a branch
5) main / (root)
6) افتح الرابط من Chrome على الجوال واسمح بالكاميرا.
7) Add to Home screen / Install app

مهم:
- الكاميرا تحتاج HTTPS، وGitHub Pages يوفر HTTPS.
- أفضل توافق: Chrome على Android.
